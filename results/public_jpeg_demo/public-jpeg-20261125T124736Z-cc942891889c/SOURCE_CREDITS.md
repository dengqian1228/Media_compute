# 公开 Clip-art 素材与处理说明

这些图形来自 OpenMoji 官方仓库，是外部已公开作品，不是本组绘制或AI生成。用于有干净参考的受控 JPEG 压缩实验；不冒充论文原图。

- **OpenMoji 狐狸（彩色）**：Sofie Ascherl；[原作品](https://github.com/hfg-gmuend/openmoji/blob/5acb7f049c45c57a98449122d470de9f09bb6794/color/svg/1F98A.svg)；[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。
- **OpenMoji 乌龟（线稿）**：Robert Winslow；[原作品](https://github.com/hfg-gmuend/openmoji/blob/5acb7f049c45c57a98449122d470de9f09bb6794/black/svg/1F422.svg)；[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。

原SVG、上游署名元数据与许可证完整归档。CairoSVG在白背景栅格化为256×256，狐狸保存RGB、乌龟线稿保存L；随后生成JPEG、L0恢复和展示裁剪。上述衍生图继续按CC BY-SA 4.0提供。精确版本、转换环境、时间、参数、摘要见manifest.json。干净参考定义为本组此次受控压缩之前的PNG，不是实拍真值。
