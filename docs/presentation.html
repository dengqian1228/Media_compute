02 · 用非零梯度的“位置数”控制结构

minS ‖S − I‖² + λ C(S)
C(S) = #{p : Σc [(DxS)² + (DyS)²] > 0}

保真项

让结果接近输入，限制任意改变颜色与结构。

稀疏梯度

统计梯度存在的位置，抑制低幅度纹理；RGB按像素联合判断。

λ 增大：细节更少；也可能把有用的细线、砖缝一起抹去。

依据 Xu 等，Image Smoothing via L0 Gradient Minimization，2011；本组核心由数组运算实现。

03 · 交替更新：阈值辅助梯度，再用 FFT 求图像

S=I
β=2λ→周期差分
联合阈值→FFT更新 S→β←κβ
β<10⁵则循环
q = Σc(gx²+gy²) ≤ λ/β ⇒ h=v=0
Ŝ = [Î + β(D̄xĥ + D̄yv̂)] / [1 + β(|Dx|²+|Dy|²)]

周期边界使差分算子可在频域求解；最后一行／列连接第一行／列。

κ 控制 β 的增长步幅，会影响轮数与输出；不会只改变速度。

代码：core.py；验证：周期边界、阈值等号、独立小矩阵求解。float64 原结果保留，显示PNG才裁剪量化。
