# L0 梯度最小化：下一阶段学习与核对提纲

状态：**待学习、待由成员描述并核对**。以下是问题清单，不是已确认的算法解释、实现方案或验证结论。课程给出的算法范围见 [requirements.md](requirements.md)；第 4 题原文见上一级目录《大作业选题汇总.pdf》第 7 页。

1. **输入与输出**：灰度、彩色图像各采用什么数组形状和通道顺序？读取后与保存前的值域、数据类型如何处理？尺寸或通道的边界情况怎样定义？
2. **目标函数与 L0 计数**：怎样准确写出保真项和非零梯度位置计数？“非零”按像素、方向、通道如何联合判断？λ 控制的平衡怎样用自己的话说明？
3. **周期前向差分及伴随**：水平、垂直前向差分的索引和周期边界是什么？其伴随算子如何推导、如何用小矩阵核对符号和方向？
4. **联合阈值**：同一像素的两个梯度方向与所有颜色通道怎样共同计算阈值量？灰度图是怎样的特例？等号边界如何处理？
5. **辅助变量更新**：引入 `h, v` 后，每次固定图像或固定辅助变量分别求解什么？更新顺序如何与题目原文对应？
6. **FFT 求解**：周期差分的频率响应、分子和分母如何由二次子问题推出？每个通道的频域求解、逆变换与实部处理怎样核对？
7. **参数和停止条件**：λ、κ、初始 β、β 上限各有什么作用及合法范围？`β ← κβ` 与停止判断的顺序如何定义？迭代次数如何记录？

下一阶段先由成员 A 提供本人理解、公式及步骤；双方核对后，再决定具体实现和验证输入。智能体的解释或自动测试不能记为成员已理解或人工核验。
