## 两人都应能回答的核对题

| 问题 | 应能解释的关键点／代码证据 |
| --- | --- |
| 为什么叫L0，而不是普通模糊？ | 非零梯度位置计数；保真项与稀疏项权衡；不等同于高斯平均。 |
| 彩色图如何避免每通道各判一次？ | `core.py:_threshold_gradients` 对方向和通道求q，同像素共用掩码。 |
| 阈值等号落在哪一边？ | `q≤λ/β`同时置零；代码 `keep=q>λ/β`，有等号测试。 |
| 为什么能用FFT？周期边界有什么代价？ | 周期差分可频域对角化；边缘两端相接可能引入不自然影响。 |
| FFT分子为什么有共轭？ | 对应差分算子的伴随；已有小矩阵二次子问题独立对照，成员需会说明推导。 |
| λ和κ分别控制什么？ | λ是稀疏惩罚强度；κ是β续增步幅，影响轮数、优化路径和输出。 |
| 为什么βmax是1e5？ | 本项目题面上标已核对；实现先更新再乘κ，β≥上限停止。 |
| 保存的PNG为什么和NPY不同？ | NPY保留未裁剪float64；PNG显示时裁剪量化，指标主表针对8位图。 |
| 为什么必须统一Canny参数？ | 避免检测阈值变化掩盖平滑差异；少线不等于保留了正确轮廓。 |
| PSNR／SSIM的真值是谁？ | 同一张未经历JPEG的干净合成PNG，不能用论文恢复图或压缩图当真值。 |
| RGB SSIM能与其他库默认值直接比吗？ | 必须对齐通道、值域、窗口、总体／样本矩、边界与下采样；本组RGB等权。 |
| 为什么Q70强平滑变差？ | 小梯度也可能是真实细线，L0无法仅靠幅度辨别“伪影”与“有用结构”。 |
| 实验怎样重复、怎样发现伪造或损坏？ | 保存输入hash、参数、JPEG量化表与输出；check重算指标并抽查重跑，存在缺失／篡改负例。 |
| 哪些工作由AI做、哪些由成员做？ | AI实际执行代码、实验、检查与材料整理；成员理解／人工核验／排练／课堂展示按实际情况回答，不声称尚未做过。 |
| 做完代码是否等于得到剩余30分？ | 不等于；材料与可运行证据已准备，评分及本人现场展示由课程验收决定。 |

上述答案是待学习与核对的提纲，不能直接登记为成员已经理解。两位成员应阅读代码和实际结果，用自己的话解释，并按真实时间补上人工检查记录。
